Start your AI Session

  • 01
    Extract to project folder

    Unzip your downloaded kit directly into your project's root directory (e.g. .playbook/).

  • 02
    Attach entry file

    Provide your AI tool with the .playbook/_index.md file at session start.

  • 03
    Send prompt

    Paste this prompt to kick off self-governed execution:

    Start a Playbook session. Follow the Session Start in the attached _index.md.
💡 In-Session Assistant: Once active, you can ask your AI what Playbook is or request real-time guidance on workflows, rules, or next steps anytime during your session.

How Playbook Works

⚡ Zero Context Drift

Core rules and active states are checked at every session start, keeping AI focused on exact project goals.

🛡️ Self-Governing Execution

Strict review gates and logging rules force the AI to document progress and ask before making assumptions.

📁 Pure Markdown

No vendor lock-in. Works across ChatGPT, Claude, Gemini, Cursor, VS Code, and any LLM chat interface.
